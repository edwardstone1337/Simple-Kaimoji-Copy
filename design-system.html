Design system

Two tiers. The --n-* colour primitives exist only to define the semantic tokens beneath them. Components must reference semantics, never --n-* directly. Structural primitives (--step, --r-*, --bw-*, --fs-*, --dur-*, --z-*) are meant to be used directly. Everything below reads live from styles.css, so it cannot drift.

Semantic colour

Contrast floors

Text pairings must clear 4.5:1 and UI component boundaries 3:1, in both themes. These are measured live against --surface.
